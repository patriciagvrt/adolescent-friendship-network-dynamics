# Adolescent Friendship Network Dynamics

Longitudinal social network analysis of best-friend nominations among
secondary-school students using stochastic actor-oriented models (SAOMs).

This project examines how reciprocity, sex homophily, and triadic closure
contribute to the evolution of adolescent friendship networks over time.

## Research Questions

The analysis investigates whether:

1. students preferentially nominate same-sex peers as best friends,
2. friendship networks exhibit triadic closure,
3. individual-level characteristics influence friendship nomination behaviour.

## Data

The project uses the Networks and Actor Attributes in Early Adolescence
dataset collected by Andrea Knecht.

The analysis focuses on classroom 09f across waves V, X, and Y.

The original data are not redistributed in this repository.

## Methods

- Longitudinal social network analysis
- Stochastic Actor-Oriented Models
- RSiena
- Network descriptives
- Jaccard stability
- Reciprocity
- Homophily
- Transitive triplets
- Degree-related effects
- Goodness-of-fit simulation
