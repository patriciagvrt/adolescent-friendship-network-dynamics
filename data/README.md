# Data

This project uses the Networks and Actor Attributes in Early Adolescence
dataset collected by Andrea Knecht.

The original dataset is distributed through the DANS Data Station
Social Sciences and Humanities and is not redistributed in this repository.

Dataset citation:

Knecht, A. (2004). Network and actor attributes in early adolescence.
DANS Data Station Social Sciences and Humanities.

The analysis uses directed "best friends" nominations from classroom 09f
across waves V, X, and Y.
